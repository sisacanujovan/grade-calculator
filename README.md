# 🎓 Student Grade Calculator

A simple and responsive **Student Grade Calculator** built using **HTML, CSS, and JavaScript**. It allows users to enter marks for multiple subjects and instantly calculates the total, average, grade, and pass/fail status.

---

## 📸 Preview

A clean and modern interface with:

* 📚 Subject-wise mark entry
* 🧮 Total marks calculation
* 📊 Average percentage
* 🏆 Automatic grade generation
* ✅ Pass/Fail result
* 📱 Responsive design

---

## ✨ Features

* Enter marks for **6 subjects**
* Input validation (0–100)
* Calculates:

  * Total Marks
  * Average Percentage
  * Grade
  * Pass/Fail Status
* Reset all fields
* Mobile-friendly UI
* Modern card-based design

---

## 🚀 Getting Started

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Install the **Live Server** extension (optional but recommended).
4. Open `index.html`.
5. Click **Go Live** or open `index.html` in your browser.

---

## 📖 How to Use

1. Enter marks for all six subjects.
2. Click **Calculate**.
3. View:

   * Total Marks
   * Average
   * Grade
   * Pass/Fail Status
4. Click **Reset** to clear all fields.

---

## 🏆 Grade Criteria

| Average (%)                      | Grade |
| -------------------------------- | ----- |
| 90 – 100                         | A+    |
| 80 – 89                          | A     |
| 70 – 79                          | B     |
| 60 – 69                          | C     |
| 50 – 59                          | D     |
| Below 50 or any subject below 35 | F     |
